# 공개 검증 기록

이 문서는 비공개 원본 문서, 화면, 경로, 정답 문장과 협업 대화를 포함하지 않는 집계 기록입니다. 2026-10-14 개발 검증 기준이며 새 릴리스의 동작을 보증하지 않습니다. 릴리스 빌드는 동일 소스에서 다시 만들고 검증해야 합니다.

## OCR 품질의 평가 범위

5개 화면과 대응 PDF 페이지의 **원본 PDF에 등록된 글자 2,811개**를 위치로 대응했습니다. 한글 NFC 정규화 후 공백을 제외한 글자 기준 CER이며 누락된 글자도 오류에 포함합니다. WER은 공백으로 나눈 어절 기준입니다.

| 입력 | 위치 대응 CER | `max(0, 1-CER)` | WER |
|---|---:|---:|---:|
| 화면 이미지 | 3.9488% | 96.0512% | 약 33.74% |
| PDF 150 DPI 이미지 | 4.0555% | 95.9445% | 약 34.23% |

이 수치는 일부 자료의 글자 위치 대응 평가입니다. 모든 페이지가 95%를 넘지는 않았습니다. PDF에 등록된 정답 글자가 없는 그림 내부 글자는 평가에서 제외했습니다. 전체 읽기 순서, 표 구조, 글꼴·자간·색상, 사진·손글씨·기울어진 문서의 정확도를 나타내지 않습니다. 인식 신뢰도는 실제 글자 정확도가 아닙니다.

가로 숫자표의 별도 실제 입력 회귀에서 기대값 9개 중 일치 수는 수정 전 3개에서 수정 후 9개로 늘었습니다. 해당 시험의 CER은 26.3158%에서 0%, WER은 69.2308%에서 0%로 낮아졌고, 그림 보존 과정에서 손상되던 글자 내부 픽셀 1,773개는 0개가 됐습니다. 이 입력에서 검출된 38.22 px 글자 크기와 약 150 DPI를 HWPX의 18.34 pt로 변환했습니다. 실제 입력 10개를 같은 모듈로 다시 처리한 회귀 시험도 통과했고 위 2,811글자 평가의 CER·WER은 유지됐습니다. 이 결과를 모든 한글 문서·표·글꼴의 정확도 보증으로 확대하지 않습니다.

## 구현 검증

단위·합성 시험은 자원 계획, 대형 이미지 분할, 파일 경로 방어, 편집 자료의 비밀값 제거, HWPX ZIP/XML, 그림 보존, 프로세스 종료와 작업 자료 수명 등을 다룹니다. 공개 CI는 비공개 원본이나 별도 모델 가중치를 다운로드하지 않습니다. 해당 자료가 없어서 생략된 시험은 전체 통과로 계산하지 않습니다.

2026-10-14 Python 3.12 개발 환경에서 모델과 비공개 원본이 있는 최종 소스의 115개 시험을 모두 실행해 25.536초에 통과했습니다. Windows PowerShell 5.1 설치 스크립트의 UTF-8 BOM과 설치 파일의 빌드 입력 해시 회귀 시험도 포함합니다. 공개 파일 176개를 새 폴더로 복사하고 `SCANEDIT*`, `PRIVATE_PDF`, `PYTHONPATH`, `PYTHONHOME` 설정을 제거한 별도 시험은 115개 중 112개 실행·통과, 3개 생략으로 16.480초에 끝났습니다. 생략된 시험은 별도 OCR 모델이 필요한 1개와 비공개 PDF가 필요한 2개입니다. 이 결과는 개발 PC의 공개 소스 사본 시험이며 GitHub Actions 실행과 구분합니다.

이 보완은 앱·모델 코드의 변경을 포함하지 않습니다. 이전 `3c6857…` 실행 파일과 CArchive의 실제 PKG·내장 항목 내용·옵션은 일치했습니다. `_internal`에서 달라진 `base_library.zip`도 내부 bytecode 내용은 일치하고 ZIP 메타데이터가 달랐습니다. 이 동등성 확인에 근거해 아래 `3c6857…`의 프로그램 시험을 최종 `6fb681…` 설치본의 근거로 함께 사용하되 실제 시험 대상 해시는 구분합니다. 최신 빌드의 한글 뷰어 표시는 Windows 잠금으로 미확인 상태입니다. 이전 `fc27d1…`의 원본 글자 PDF 5쪽·가로표 표시 확인을 최신 빌드의 표시 확인으로 확대하지 않습니다.
