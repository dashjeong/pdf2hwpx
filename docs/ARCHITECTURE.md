# 스캔노트 구조

스캔노트는 Windows 실행 파일 또는 Python에서 루프백 FastAPI 서버를 시작하고, 외부 CDN 없이 브라우저 편집 화면을 제공합니다. 입력을 페이지별로 처리해 원본 좌표를 가진 편집 자료를 만들고 HWPX 또는 독립 HTML로 내보냅니다.

```mermaid
flowchart LR
  A[PDF 또는 이미지] --> B[파일과 자원 검사]
  B --> C{PDF 원본 글자 층}
  C -->|있음| D[글자와 표 좌표 직접 추출]
  C -->|없음| E[한국어 ONNX OCR]
  E --> F[선과 셀·그림 구성]
  F --> G[페이지별 디스크 자료]
  D --> G
  G --> H[원본과 편집 화면 비교]
  H --> I[HWPX 또는 독립 HTML]
  E -->|선택 및 자원 충족| J[소형 AI 부분 검수]
  J --> G
```

PDFium이 PDF 렌더링과 원본 글자 정보를 제공합니다. 회전하거나 유효 페이지 영역의 원점이 이동한 PDF는 렌더된 이미지의 OCR 경로를 사용해 원본 PDF 좌표와 화면 좌표의 혼용을 피합니다. 스캔 OCR은 RapidOCR와 ONNX Runtime CPU를 사용합니다. 대형 이미지 디코딩은 분리된 작업 프로세스와 libvips를 사용하며 분할 이미지의 좌표를 원본 공간으로 되돌립니다. API 모드의 이미지 전송과 축소는 별도 경로입니다.

HWPX 내보내기는 일반 글자를 section의 본문 문단(`hp:p/hp:run/hp:t`)으로 기록합니다. 같은 행의 글꼴·낱글자 조각은 여러 run을 가진 한 문단으로 묶고, 들여쓰기·줄 간격·탭으로 원본 배치를 참고합니다. 일반 글자를 글상자나 표로 감싸지 않습니다. 표 블록만 실제 표와 셀로, 이미지 블록만 포함된 그림으로 기록합니다. 표·도형·그림의 원본 위치는 유지하므로 본문을 크게 늘려 편집하면 해당 개체의 위치도 한글에서 조정할 수 있습니다.

`editable_graphics`는 PDF의 선·사각형·곡선과 스캔의 직선·테두리를 `shape`로 분리합니다. 곡선은 허용 오차 내의 꼭짓점으로 구성한 편집형 다각선입니다. HWPX는 이를 `hp:line/rect/polygon/curve`로 저장하고, 웹·HTML은 SVG로 표시합니다. 표의 방향별 선 색·두께와 셀 채움은 `borderFill`로 기록합니다. 사진과 복잡한 잔여 그림만 국소 PNG 그림으로 보존하고, 문서 양식을 전체 배경 그림으로 대신하지 않습니다. 원래 글자 정보는 그래픽 분리 전 추출하므로 그림 마스크가 글자·숫자 인식 입력을 변경하지 않습니다.

원본 글꼴을 대신하는 Windows 글꼴이 더 넓은 경우 초기 본문의 수평 글자 비율을 원본 글자 영역에 맞춥니다. 글자 높이는 유지하며 사용자가 수정한 문장은 정상 본문으로 줄바꿈합니다. 기존 배경형 편집 자료의 내보내기도 좌표 배율을 보존하며 양식 분리를 수행하고, 이전 처리 버전의 중단 작업을 새 처리 버전으로 섞어 재개하지 않습니다. 대형 이전 배경은 전체 디코딩 전에 거부해 원본의 분할 재변환을 안내합니다.

최대 입력은 1 GiB, 500쪽입니다. 자원 계획은 가용 메모리에서 여유를 남기고 8 GiB까지 사용량을 계획합니다. 메모리 조회 실패 시 2 GiB 기준으로 계획합니다. OCR 스레드는 최대 4개, 인식 배치는 4개이며 문서는 한 쪽씩 처리합니다. 계획과 이미지 분할은 자원을 줄이는 장치이며 모든 입력의 운영체제 메모리 상한을 보증하지 않습니다.

페이지별 편집 자료와 그림은 디스크에 보관합니다. 내보내기는 ZIP/HTML에 순차 기록하고 다운로드는 서버의 결과 파일을 직접 제공합니다. 페이지 수가 많아도 출력 형식별 결과 파일은 하나입니다. 브라우저의 화면 편집량과 저장 공간은 입력에 따라 늘어납니다.

완료 페이지 JSON은 원자적으로 교체하고 메모리에서 방출합니다. 진행 조회는 상태만 반환하며 화면은 페이지 단위로 읽고, 수정하지 않은 먼 페이지를 비웁니다. 중단한 작업은 원본 SHA256·처리 버전·페이지 및 이미지 자료를 검증한 뒤 완료 페이지를 재사용합니다. 변환·AI 준비·저장·품질 측정은 하나의 자원 입장 제어를 공유합니다. 현재 앱과 소유 자식의 private commit·working set을 측정하며 브라우저를 합산하지 않습니다. 예측 예산과 자식의 강제 commit 제한은 다른 범위입니다.

소형 AI는 한국어 OCR의 좌표·표·그림을 유지하면서 어려운 글자 최대 2줄만 검수합니다. 제안은 원문·숫자·좌표에 자동 적용하지 않습니다. 자원이 부족하거나 모델 응답이 실패하면 기본 OCR 결과를 보존합니다. 모델 프로세스는 앱이 소유하고 종료·유휴 처리 시 정리합니다.

API 키는 화면과 요청 메모리에만 보관합니다. 외부 Origin의 쓰기를 제한하고, 내보내기 그림 경로를 해당 작업 안으로 검사합니다. HTML/XML 특수문자는 이스케이프하며 페이지 문구를 실행 명령으로 사용하지 않습니다. 로컬 작업 자료는 종료 후 남을 수 있습니다.

공개 품질 평가와 한계는 [공개 검증 기록](VALIDATION_PUBLIC.md)에 있습니다. 실행 파일의 빌드 manifest는 소스와 실행 파일 해시를 기록하고, 패키징 시 최종 소스와 일치하는지 확인합니다.
